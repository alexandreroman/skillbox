# Node.js / TypeScript

Run the appropriate scaffolding command:

- **Plain Node.js**: the `init` command of pnpm
- **Next.js**: `pnpm dlx create-next-app@latest . --ts`
- **Vite + React**: `pnpm create vite . --template react-ts`
- **Vite + Nuxt**: `pnpm dlx nuxi@latest init .`

Ask the user to confirm the framework choice if not
explicitly stated. See
[Node.js / TypeScript tooling](../../project-rules/references/nodejs-typescript/tooling.md)
for the preferred option.
